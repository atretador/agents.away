Set up Agents Away

Once per phone, about two minutes.

✓No certificate needed: the pairing code tells the app which certificate to trust, for this PC only.

Download it, open the file and install. Android asks to allow your browser to install apps: allow it for this install.

Pair with this PC

Required

On the PC run agents-away pair. In the app tap Scan QR code and scan the second QR code (the pairing link). It works once, within 10 minutes.

3

Allow notifications

Recommended

When the app asks, allow notifications and let it run without battery restrictions, so it can tell you when a session needs you.

The web app runs in your browser and is added to the home screen. The phone has to trust your PC's private certificate first.

1

Download the certificate

Required

It lets this phone trust your PC's HTTPS (needed for notifications). It's made on your PC and can only vouch for local addresses.

↓ Download certificate
Check the fingerprint
When the phone shows the certificate's details, its SHA-256 fingerprint must match the one agents-away pair prints on the PC.
2

Install the certificate

Required
Android
  1. Settings → Security & privacy → More security settings → Encryption & credentials
  2. Install a certificate → CA certificate → Install anyway → pick agents-away-ca.crt
iPhone
  1. Settings → Profile Downloaded → Install
  2. Settings → General → About → Certificate Trust Settings → turn on “Agents Away local CA”
3

Pair

Required

On the PC run agents-away pair and scan the second QR code (the pairing link) with the camera. It works once, within 10 minutes.

4

Add it to the home screen

Recommended

Browser menu → Add to Home screen (iPhone: Share → Add to Home Screen). Open it from there and tap Turn on for notifications.

Open Agents Away
