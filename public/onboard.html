Set up Agents Away

You only need to do this once per phone.

1Download the certificate

This lets the phone trust the PC's HTTPS (needed for notifications). It's a private certificate made on your PC. When the phone shows the certificate's details, check its SHA-256 fingerprint matches the one agents-away pair printed on the PC.
Download certificate

2Install it

Android:
  1. Settings → Security & privacy → More security settings → Encryption & credentials
  2. Install a certificate → CA certificate → Install anyway → pick agents-away-ca.crt
iPhone:
  1. Settings → Profile Downloaded → Install
  2. Settings → General → About → Certificate Trust Settings → turn on “Agents Away local CA”

3Pair

On the PC run agents-away pair and scan the second QR code (the pairing link). Then use the browser menu → Add to Home screen, open Agents Away from the home screen and tap Turn on for notifications.
